# This is the Android client for [VirtualWallet-Wallty](https://github.com/VirtualWallet-Wallty)

</div>

> Requires Android Studio and a device/emulator running API 32+.

```bash
git clone https://github.com/VirtualWallet-Wallty/android
```

### 1. Open the project in Android Studio

### 2. Set the backend base URL in the network configuration file

### 3. Run on emulator or physical device
